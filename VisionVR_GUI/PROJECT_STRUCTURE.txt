USAGE EXAMPLES
--------------

1. VERIFY INSTALLATION
   $ cd VisionVR_GUI
   $ python3 verify_installation.py

2. RUN THE GUI
   Linux/macOS:  $ ./run_gui.sh
   Windows:      > run_gui.bat

3. CONFIGURE SETTINGS
   - Open Settings tab
   - Adjust parameters
   - Select image sets
   - Save config (optional)

4. ENTER USER DETAILS
   - Switch to User Details tab
   - Fill in information
   - Click "Start Session"

5. RUN VR GAME
   - Launch Unity VR Game
   - Game reads settings automatically

6. VIEW RESULTS
   - Return to Python GUI
   - Switch to Results tab
   - Browse session data

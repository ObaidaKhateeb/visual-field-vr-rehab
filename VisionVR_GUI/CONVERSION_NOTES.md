# Unity to Python Conversion Notes

## Project Overview

This document describes the conversion of the Vision VR GUI from Unity C# to Python with tkinter.

## Original Unity Project

**Location:** `/workspace/VISION VR GUI/`

**Main Components:**
- `CalibrationUI.cs` - Main GUI script (1421 lines)
- `vr_settings.json` - Settings template
- Unity UI prefabs and scene

**Dependencies:**
- Unity Engine 2020.3+
- Unity UI system
- TextMeshPro

## New Python Project

**Location:** `/workspace/VisionVR_GUI/`

**Main Components:**
- `vr_calibration_gui.py` - Main application (850+ lines)
- `requirements.txt` - Dependencies (none required!)
- `README.md` - Documentation
- `run_gui.sh` / `run_gui.bat` - Launch scripts

**Dependencies:**
- Python 3.7+
- tkinter (included with Python)

## Migration Path

If you want to switch from Unity GUI to Python GUI:

1. **No data migration needed** - Uses same files
2. **Install Python 3.7+** if not already installed
3. **Copy VisionVR_GUI folder** to your system
4. **Run the GUI** with `python vr_calibration_gui.py`
5. **Existing configs and data** work immediately
